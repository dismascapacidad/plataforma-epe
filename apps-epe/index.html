Equipar para Equipar

Apps EpE

Juegos y ejercicios propios, para probar y usar en sesión.

Compatible dis+capacidad Piano de 7 notas App para practicar la selección con switch tocando las 7 notas del piano. Compatible dis+capacidad Barrido App para entrenar la habilidad de barrido, por tiempo o con 2 pulsadores, copiando una palabra. Compatible dis+capacidad Vincular imagen-botón App para practicar la asociación de imágenes propias con voz y tecla, de 1 a 8 casilleros. Compatible dis+capacidad Lado Correcto Juego para entrenar la reacción y la lateralidad respondiendo con las flechas del teclado. Compatible dis+capacidad Duración de pulsación Juego para practicar la diferenciación entre pulsaciones cortas y largas de un botón. Compatible dis+capacidad Torre de Hanói Juego para entrenar la planificación pasando una torre de discos de una varilla a otra. Compatible dis+capacidad N-back Juego para entrenar la memoria de trabajo comparando cada estímulo con el de N pasos atrás. Compatible dis+capacidad Stroop Juego para entrenar el control inhibitorio respondiendo al color de la tinta, no a la palabra. Compatible dis+capacidad SimoNeuro Juego de memoria de secuencias ("Simón dice") con 4 colores, con modos de interferencia audiovisual. Compatible dis+capacidad Comunicación con seguimiento de cabeza App para practicar la escritura con la cabeza y un pulsador, con salida por voz.
